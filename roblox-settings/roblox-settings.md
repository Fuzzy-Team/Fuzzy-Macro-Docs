# Roblox Settings

Make sure your Roblox settings are set as follows:

* Camera Mode: **Classic**
* Camera Sensitivity: **1** when using Vic Hop or Stinger Hunt
* Movement Mode: **Default (Keyboard)**
* Fullscreen: **On**
* Performance Stats: **Off**
* Micro Profiler: **Off**
* Camera Inverted: **Off**
* UI Navigation Toggle: **On**
* Experience Language: **English**
* Background Transparency: **0**

Vic Hop and Stinger Hunt use mouse camera movements that require sensitivity 1. This also changes how fast the camera turns when you play manually. Fuzzy does not change this Roblox setting for you.

{% hint style="info" %}
NOTE: If you are using fast flags, ensure that "DFIntDebugFRMQualityLevelOverride" is set to 4 or above. (If you don't know what that is you can ignore it)
{% endhint %}
