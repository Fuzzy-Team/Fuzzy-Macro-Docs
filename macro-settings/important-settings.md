# Important settings



{% stepper %}
{% step %}
### Set your movespeed

Go to Config -> Bee Swarm.\
To check your movespeed, open the BSS settings panel and scroll down until you find the walkspeed stat.
{% endstep %}

{% step %}
### Ensure your preferred hive slot is correct (do this every time you run the macro).

Go to Config -> Bee Swarm -> Hive and check Preferred Hive Slot. The macro claims that hive first, and takes the open hive closest to it if it is taken.
{% endstep %}

{% step %}
### Ensure your sprinkler type and hotbar slot are correct

Go to Config -> Bee Swarm -> Hotbar Items and confirm Sprinkler Type and Sprinkler Slot. If you turned on Top Navigation, these are on the Boost tab under Hotbar Item Slots instead.
{% endstep %}

{% step %}
### Make sure game mode is off (IMPORTANT).

Fullscreen Roblox, move your mouse to the top, click the controller icon, and make sure that game mode is off.
{% endstep %}

{% step %}
### Close unnecessary applications

Close all unnecessary applications, as they may cause lag in the game.
{% endstep %}
{% endstepper %}

## Finding settings

The **Config** tab is split into sub-tabs:

* **Bee Swarm**: hive, movespeed, hotbar items, how the macro travels, converting
* **Task Priorities**: the order tasks run in (see [Macro modes and task order](macro-modes.md))
* **Rejoin & Recovery**: private server links, rejoin attempts, scheduled rejoin
* **App Settings**: display, keybinds, updates, and appearance
* **Discord**: webhook, bot, and stream
* **User Profiles**: create, switch, import, and export profiles

Under **App Settings → Appearance** you can turn on **Top Navigation** to show the tabs in a bar across the top instead of the sidebar. The window reloads when you change it. **GUI Theme** changes the colors, and the six **Custom** color boxes (Background, Sections, Buttons and Inputs, Text, Accent, Accent Text) let you set your own as six hex digits, like `#00FF00`. Editing one switches the theme to Custom Theme.
